About game

It is a simple quiz game. Every game has 5 categories and each category consists of options of varying value. Higher the value harder the questions. The game is started my one player pick one of the options. The option will show a question and all the players are able to answer, first to answer the question will chosen. If the player guesses the right answer the player gets the points equal to the value of the option or lose points if wrong answer. The player also gets to pick the next option.
